# AgentPulse 设计原型（design/）

本目录承载 AgentPulse 的设计规格与可点击原型，用于在写代码之前走查界面。

```
design/
├── README.md            ← 本文件
├── spec.md              ← 设计规格（与 /home/Yuhang/agentpulse/firstmate/data/agentpulse-design/report.md 逐字一致）
└── prototype/           ← 纯 HTML/CSS/JS 可点击原型（无框架、无构建、无网络）
    ├── index.html       ← 唯一入口
    ├── tokens.css       ← 设计令牌（§4.2 调色板 / 字号 / 间距 / 圆角 / 动效，全部为 CSS 自定义属性）
    ├── app.css          ← 走查外壳 + 安卓四屏 + 横屏 / 平板 + TUI 样式
    ├── data.js          ← 模拟数据模型（任务 / 告警 / 事件流 / 连接与数据状态）
    ├── tui.js           ← Debian TUI 字符网格渲染器（80×24 与 160×48，真实制表符，非图片）
    └── app.js           ← 视图渲染与交互（状态切换、浮层、模拟推流、键盘快捷键）
```

## 原型覆盖范围

- **安卓四屏**（`spec.md §4.3`，手机外壳 390×844）：
  1. 总览大盘（Overview）
  2. 任务与 Agent 矩阵（Tasks，含筛选与任务卡片）
  3. 实时动态流（Live feed，模拟推流 + 自动滚动）
  4. 异常提醒与阻断（Alerts，含「复制指令」按钮）

  底部导航切换四屏，点击任务卡片打开底部详情浮层（Detail Sheet）。
- **连接状态三态**（`§3.2 C`）：Healthy / Stale / Disconnected，切换后顶栏横幅、降级透明度、
  重连退避计数实时变化。
- **数据状态三态**：有数据 / 空 / 错误，分别呈现完整数据、空状态与「HTTP 500 聚合失败」错误态。
- **横屏与平板布局**（`§4.5`）：横屏左 Navigation Rail + 40% / 60% 双联；平板 25% / 45% / 30% 三栏看板。
- **Debian TUI**（`§5.2 / §5.3`）：80 列 × 24 行与 160 列 × 48 行两种终端画面，用真实盒线字符与
  §5.3 的 16 色降级映射表实时合成（CJK 按终端双宽计列，不使用图片 / emoji）。
- 右侧「设计说明」面板随视图切换，标注每个界面对应的规范章节。

## 如何打开

无需构建、无需安装、无需联网，两种方式任选：

```bash
# 方式一：直接双击用浏览器打开（file:// 即可运行）
# 浏览器打开 design/prototype/index.html

# 方式二：本地静态服务器（推荐，行为与生产一致）
cd design/prototype
python3 -m http.server 8000
# 然后浏览器访问 http://127.0.0.1:8000/
```

顶部「控制条」可切换：视图（手机竖屏 / 横屏 / 平板 / Debian TUI）、连接状态、数据状态、工作流场景、
缩放（适应窗口 / 100%）。快捷键：`1`–`4` 切换四屏、`Esc` 关闭浮层、`T` 切换 TUI 尺寸。

## 重要说明：全部数据均为模拟

本原型**不连接任何真实服务、不读取任何真实数据源**。所有任务 ID、窗格 ID、路径、日志行、事件与
告警均为**人工构造的模拟数据**，仅用于呈现 `spec.md` 中定义的界面状态与排版，且刻意沿用报告第 2/3 章
的示例取值以便逐项比对。实时动态流由定时器合成，页面以「全部数据为模拟」徽标与「模拟推流」标签明确标注。

本目录之外的任何内容（真实监控服务、Android 原生工程、Rust TUI 源码）均不在本原型范围内。
